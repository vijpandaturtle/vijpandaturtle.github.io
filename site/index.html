Selected work

Domain LLMMistral AI + ESA · €1M

EVE: an LLM for Earth Observation

Co-designed the distributed multi-GPU training and serving stack (PyTorch, Hugging Face, vLLM), selected the Mistral base model, and built the first hallucination-mitigation module. Drove continued pre-training on a 5B-token EO corpus across 8× A100s, plus data curation, SFT and the RAG pipeline.

Paper accepted at ACL 2026.

Open sourceNGI Search / EU · €150K

Trallie

I designed and built Trallie from scratch and led the project. It's a modular, model-agnostic framework for zero- and few-shot information extraction from unstructured documents. I also coordinated the consortium through to the open-source release.

Presented at OW2con'25.

AI safetyIndependent · active

Seesaw ↗

A multi-agent framework that automates the hypothesis → experiment → critique loop in mechanistic interpretability. Three agents (Scout, Lens, Quill) plan, run and critique experiments, with a human-in-the-loop checkpoint between each stage. Each agent also runs as a standalone MCP server.

LangGraph · MCP · Python

Domain LLMESA · €400K

SatcomLLM

Project co-lead on a domain-specific LLM for satellite communications. I co-designed the training infrastructure, chose the base model and set the technical strategy. I led engineering direction and the open-source delivery.

Agents · RAGTipico · 2M+ LOC

AI code-refactoring assistant

I led the design and delivery of a multi-agent system for Tipico that extends Amazon Q. It uses custom RAG over the codebase, orchestrates agents to get around context-window limits, and comes with its own evaluation benchmark.

50% faster refactoring · 27% more cost-efficient · 12% better code quality. Evaluation paper accepted at EMNLP 2026.

DatasetHugging Face · arXiv

Roadscapes ↗

An open multi-task, multimodal dataset of 9,000+ annotated images of Indian road scenes, day and night, with QA pairs for grounding, reasoning and scene understanding. Roadscapes-Video-RAG adds a dashcam video set and a reference multimodal RAG pipeline (CLIP + LanceDB + a VLM) that gives driving advice.

23,000+ and 1,300+ downloads in the first month.
